# Simplysm Notes

[English](README.md) | 한국어

GitHub repo 를 저장소로 쓰는 Windows 노트 앱입니다. 노트는 내 GitHub repo 에만 저장되고, 앱은 그 repo 를 로컬에 복제해 두고 편집한 것을 자동으로 커밋·푸시합니다.

> 이 저장소는 **설치본 배포**와 **문의 접수**를 위한 곳입니다. 소스는 공개하지 않습니다.

## 이런 앱입니다

- **내 노트는 내 GitHub repo 에만 있습니다.** 따로 가입할 서비스나 거쳐 가는 서버가 없습니다. 앱이 없어도 GitHub 웹에서 그대로 읽힙니다.
- **저장·동기화를 신경 쓰지 않아도 됩니다.** 쓰는 대로 자동 저장되고, 앱이 알아서 GitHub 에 올리고 받아 옵니다. 다른 PC 에서 고친 내용도 자동으로 들어옵니다. 오프라인에서도 쓰고, 연결되면 올라갑니다.
- **같은 곳을 두 곳에서 고쳤으면 직접 고릅니다.** 앱이 한쪽을 몰래 버리지 않고, 병합 화면에서 양쪽을 보고 정합니다.
- **마크다운 원문을 그대로 편집합니다.** 보이는 글자가 곧 파일 내용이라, 열기만 해서 파일이 바뀌는 일이 없습니다. 제목·목록·표·코드 블록(언어별 색)을 칠해 보여 주고, 표는 칸을 맞춰 보이며 행·열을 단축키로 옮깁니다.
- **노트끼리 링크로 잇습니다.** `[[` 자동완성이나 트리에서 끌어 넣기로 링크를 넣고, Ctrl+클릭으로 엽니다. 노트나 폴더를 옮기거나 이름을 바꾸면 그것을 가리키던 링크가 함께 고쳐집니다.
- **파일·이미지를 노트에 첨부합니다.** 끌어 넣거나 붙여 넣으면 노트에 첨부되고, 이미지는 본문에 그림으로 보입니다.
- **모든 노트를 한 번에 찾습니다.** 검색창 하나로 연결한 모든 노트북의 제목과 본문을 입력하는 대로 찾습니다.
- **지난 내용을 보고 되돌립니다.** 노트·폴더마다 바뀐 내역을 보고, 무엇이 바뀌었는지 비교하고, 고른 노트만 그 전으로 되돌립니다.
- **폴더 하나를 팀과 공유합니다.** 고른 폴더를 다른 repo 로 자동 복제해 두고, 받는 사람은 그 repo 를 읽기 전용으로 엽니다. 앱이 꺼져 있어도 복제는 GitHub 에서 계속 됩니다.
- **터미널이 들어 있습니다.** 노트 폴더에서 바로 셸을 열어 Claude Code 같은 코딩 에이전트로 노트를 다뤄도, 바뀐 내용이 앱 화면에 그대로 반영됩니다.
- **알림 영역에 머뭅니다.** 창을 닫아도 동기화는 계속 돌고, Windows 를 켜면 함께 시작합니다(설정에서 끌 수 있습니다).
- 화면 언어는 한국어와 English 중에서 고릅니다.

## 시작하기

1. 아래 「다운로드」에서 설치 파일을 받아 실행합니다.
2. **GitHub 로 로그인**합니다. 앱이 보여 주는 코드를 GitHub 페이지에 붙여 넣고 승인하면 됩니다.
3. **노트북으로 쓸 repo 를 연결**합니다. 내 repo 목록에서 고르거나 `owner/repo`·주소를 넣습니다. 쓰기 권한이 없는 repo 는 읽기 전용으로 열립니다.

## 다운로드

[Releases](../../releases/latest) 에서 `notes-win32-x64-<버전>.exe` 를 받아 실행하세요.

- Windows 10/11 (64비트)
- 관리자 권한이 필요 없습니다. 사용자 폴더에 설치됩니다.
- git 은 앱에 함께 들어 있어 따로 설치하지 않아도 됩니다.

## 설치할 때 나오는 파란 경고 (SmartScreen)

이 설치본에는 아직 **코드 서명이 없습니다.** 그래서 처음 실행하면 Windows 가 "PC 보호"라는 파란 창을 띄웁니다.

1. **추가 정보** 를 누릅니다.
2. **실행** 을 누릅니다.

서명은 사용자가 늘어나면 도입할 예정입니다.

## 업데이트

앱이 새 버전을 스스로 내려받아 두고, 준비되면 창 위쪽에 **업데이트 설치** 버튼이 나타납니다. 그 버튼을 누를 때만 재시작하며 적용됩니다 — 작업 중에 끼어들지 않습니다.

## 데이터가 있는 곳

- 노트: 연결한 GitHub repo, 그리고 그 repo 의 로컬 복제 폴더(기본 `문서\Simplysm Notes\<owner>\<repo>`)
- 앱 설정: `%APPDATA%\Simplysm Notes`

앱을 지워도 노트 폴더는 남습니다.
